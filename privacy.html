Privacy Policy

Last updated: 2 November 2026

This policy covers MishChief rclone, a personal tool that backs up stream recordings from the owner's computer to the owner's Google Drive.

Who uses it

Only the owner. It is not offered to anyone else, and it collects no data from other people.

What Google data it accesses

With the owner's permission, it accesses the owner's Google Drive files and folders through the Google Drive API, to upload, list and check backups.

How the data is used and stored

Drive data is used only to run these backups. The Google login token is stored only on the owner's own computer. The tool has no server of its own, and files move only between that computer and Google Drive. The owner sometimes runs the tool through an AI coding assistant on that computer, which can see file names and transfer logs, but not the contents of the recordings.

Sharing

The tool does not sell Google data, share it with third parties, or use it for advertising or for training AI models. Any sharing of a Drive folder, such as with the owner's video editor, is done by the owner through Google Drive itself.

Removing access

The owner can remove the tool's access at any time from Google account permissions. Backups already in Drive stay there until the owner deletes them.

Contact

Questions can go through the GitHub profile that hosts this site.
