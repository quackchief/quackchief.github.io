MishChief rclone

MishChief rclone is a personal tool. It uses rclone, an open source file transfer program, to back up stream recordings from the owner's own computer to the owner's own Google Drive.

It is not a public service. Nobody else can sign up for it, and only the owner uses it.

How it uses Google Drive

The tool uses the Google Drive API to upload, list and check files in the owner's Drive, so that recordings get backed up and can be shared with the owner's video editor.
